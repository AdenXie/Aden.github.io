# 博客结构与加载优化验证

日期：2026-09-14。修改仅在本地，未提交、推送或部署。

## 测量方法

改动前先复制原有 `public` 到 `.perf/baseline`，保留其真实外部资源引用；优化后使用统一生产构建的 `public`。两者均由相同的本地静态服务提供，文本资源启用 gzip。使用 Chrome 152.0.7977.83、390×844 移动视口、DPR 1；每次新建浏览器上下文、关闭缓存、不滚动。

每档运行三次，使用 Chrome DevTools Protocol 设置网络和 CPU 降速；记录 LCP、FCP、CLS、网络请求和收到的传输字节。等待 load 最长 180 秒，然后观察三秒。本文“传输量”指整个未滚动观测期收到的字节，包含旧版提前下载的内容，不是单纯的可见图片大小，也不是 LCP 时刻的字节数。

| 网络与 CPU | 旧版 LCP 中位数 | 优化版 LCP 中位数 | 旧版传输量中位数 | 优化版传输量中位数 | 优化版 CLS 中位数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 不限速，CPU 1× | 85.676 s | 0.224 s | 8.478 MB | 0.750 MB | 0.059 |
| 1.6 Mbps、150 ms，CPU 4× | 4.612 s | 1.952 s | 9.760 MB | 0.750 MB | 0.060 |
| 400 Kbps、400 ms，CPU 6× | 10.460 s* | 6.688 s | 2.827 MB* | 0.750 MB | 0.115 |

MB 为十进制。* 旧版慢网三次中有两次达到 180 秒上限且背景仍未完成，所记录的 LCP 对应不完整画面，传输量也不完整。旧版普通网络三次 LCP 为 3.880、88.076、85.676 秒，显示外部依赖造成了很大的波动；不能把 85.676 秒理解为所有访客的常态。旧版常规移动档也有一次 load 超时。所有异常样本保留，没有删掉后再计算结果。

优化版三档共九次均完成背景加载，无 load 超时和页面脚本异常。常规移动档 LCP 为 1.940、1.952、2.152 秒，CLS 为 0.059、0.060、0.061，达到该模拟档的 LCP ≤2.5 秒及 CLS ≤0.1 目标。相较旧版，该档观测 LCP 降低约 57.7%，传输量减少约 92.3%。

慢网优化版 LCP 为 5.944、6.688、6.736 秒；传输量相对旧版未完成样本的中位数也减少约 73.5%。记录的 LCP 中位数下降约 36.1%，但由于旧版两次背景未完成，不能把这当成完整画面的严格等价验收。慢网 CLS 中位数为 0.115，仍存在位移；原有打字动画和可变长度的一言文案保留，没有用关闭效果来降低指标。

本次是本地浏览器模拟，静态资源没有经过生产域名的真实 DNS、TLS、边缘节点和服务器响应时间；外部服务则使用当时真实网络。它验证了加载顺序和依赖隔离的改进，不代表中国大陆、澳洲或所有设备上的线上成绩。中国大陆无实测节点，真实地区体验待部署后验证。

逐次数据保存在同目录的 `performance-results.json`；完整请求记录和截图保留在本机 `.perf`。

## 实际改动

- 当前首页原图为 4,719,749 字节；经图片核对后从同一原图生成四档 WebP，640/960/1280/1920 像素宽分别约 158/316/509/853 KB。旧的 `source/images/home-hero.jpg` 是另一张照片，没有误用。
- 主题主入口打包，主题资源、字体及 Twikoo 客户端同域提供；常用 solid/regular/brands 图标字体约为 4.8/5.8/1.8 KB，保留完整字体回退。样式按原顺序合并压缩。
- 1.32 MB 的中文搜索索引改为首次打开搜索时请求，正在加载、失败重试及结果刷新均验证。英文索引独立。
- 首页缩略图接近视口再加载；音乐音频点击后才请求，修复没有配置歌词时仍请求不存在歌词资源的问题；评论接近视口才加载，统计脚本异步。
- 共用组件生命周期处理重复挂载、页面离开取消请求、可取消重试延迟和隐藏页面的时钟暂停。原有缓存期限、数据校验及错误提示保留，过期汇率缓存标注为过期。
- 生产入口统一为 `npm run build:site`，双语生成后再做资源优化，并处理旧英文缓存页面的资源引用。正文、网址和 API 源文件未改动。

## 验证结果

- 通过全新 `npm ci` 安装及生产构建；主题适配文件校验通过，没有手动修改安装包。
- 58 项自动测试通过，覆盖原有天气、汇率、世界时间、双语处理，以及新增的生命周期、取消请求、取消重试和隐藏页面时钟行为。
- 180 个中英文页面资源路径、专用脚本范围、搜索及评论加载配置检查通过。
- 与原始中文静态页面对比，188 处代码/公式块文本保持一致。
- 390×844 手机和 1440×1000 桌面浏览器检查通过：首页、长文章、归档、世界时间、英文页、搜索缓存、英文搜索、搜索失败后重试、播放器请求时机、评论按需初始化、页面往返和深浅色切换。截图已检查。
- 功能测试刻意阻断所有外部服务，正文和本地导航仍可用。Twikoo 1.7.20 在远程服务被阻断时会产生值为 `0` 的 SDK 拒绝，测试单独记录该已识别的外部错误；没有将其计为业务页面正常工作，也没有全局屏蔽错误。评论没有实际发送，真实音频播放及服务可用性未作在线验收。
- 本地没有调用翻译 API；沿用缓存产生 90 个英文页面，仍有 15 个未缓存片段，按原机制保留旧译文及提示。

## 复测与发布

运行 `npm run build:site`、`node tools/verify-browser.cjs` 和 `node tools/benchmark.cjs public after`。部署前保留 `source` 分支改动的可回退版本，并通过现有发布流程；本次没有触发发布。线上复测应同时检查首次访问、缓存访问、评论/音乐服务，以及大陆与海外真实链路。
